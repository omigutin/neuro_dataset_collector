# Основные понятия

## Задача (`task`)

Для чего собираются кадры:

| Задача | Что сохраняется | Как размечено |
|---|---|---|
| `classify` — классификация | вырез зоны (или весь кадр) | папкой: `EMPTY/`, `FULL/`… |
| `detect` — детекция | вырез зоны (или весь кадр) в `images/` | файлами `labels/*.txt` с прямоугольниками (YOLO), если была модель |
| `segment` — сегментация | так же | файлами `labels/*.txt` с контурами (YOLO), если была модель |

Для детекции и сегментации без модели сохраняются только картинки — разметку потом делают в Roboflow.

## Каталог и коллекция

**Каталог** — корневая папка (`catalog.root`). В ней лежат все наборы и файл истории `catalog.sqlite`.

**Коллекция** — один набор кадров внутри каталога, например `norebo/ML` или `default`.
Название можно делить на уровни через `/` — получатся вложенные папки. Что означают уровни
(завод, линия, камера, проект) — решаете вы.

Пример каталога:

```
D:/datasets/
  catalog.sqlite            ← история (не удалять)
  norebo/ML/
    EMPTY/  FULL/  UNKNOWN/ ← классы
    _unsorted/              ← без класса (первый сбор без модели)
    _suspect/EMPTY__FULL/   ← подозрительные: модель сказала EMPTY, вокруг были FULL
```

## Зона

**Зона** — участок кадра, который вырезается и сохраняется. Зоны берутся из файла разметки LabelMe
(`regions.source: file`) или передаются программой (`api`). Если зон нет — сохраняется весь кадр.

Если зона — многоугольник, можно закрасить всё вне его чёрным (`mask_outside: true`).

## Класс

Название случая, который должна различать модель: `EMPTY`, `FULL`, `UNKNOWN`… Для классификации это
название папки. Имена классов не должны начинаться с `_` — такие папки служебные.

## Автоотбор: поводы и ограничения

Кадр сохраняется автоматически, если **сработал хотя бы один повод** и **пройдены все ограничения**.

Поводы:

- `always` — каждый кадр (для первого сбора, пока модели нет);
- `confidence` — модель сомневается (уверенность в заданном диапазоне);
- `audit` — случайная проверка: небольшая доля кадров сохраняется даже при высокой уверенности.
  Так ловятся случаи, когда модель уверенно ошибается.

Ограничения:

- `interval` — не чаще, чем раз в N секунд (для каждой зоны и класса отдельно);
- `scene_change` — картинка заметно изменилась с прошлого сохранения;
- `quota` — не больше N кадров на класс;
- `dedup` — нет почти такого же кадра среди уже сохранённых (и отклонённых).

## Проверка последовательности

Модель смотрит видео кадр за кадром. Если долго идёт «FULL», потом один-два кадра «EMPTY», а потом снова
«FULL» — скорее всего, «EMPTY» ошибочный. Такие кадры попадают в `_suspect/EMPTY__FULL/`.
Дальше человек решает, куда их перенести.

Для классов, где ошибка неочевидна (например, `UNKNOWN` — человек закрыл продукт рукой),
укажите их в `review_always`: программа отметит такие кадры, но не будет ничего предлагать сама.

Автоматическое исправление (`trusted_flips`) выключено по умолчанию. Включайте его только для пар классов,
в которых вы уверены.

## Состояния кадра

| Состояние | Что значит |
|---|---|
| ждёт проверки (`pending`) | сохранён, человек ещё не проверял |
| подозрительный (`suspect`) | лежит в `_suspect`, нужно решение человека |
| проверен (`verified`) | после сверки лежит в папке класса |
| отклонён (`rejected`) | человек удалил файл; такие кадры больше не собираются |
| ошибка (`failed`) | не удалось записать файл |

## Сверка (`sync`)

Сверка — это когда программа смотрит, что вы сделали с папками после проверки, и записывает это в историю.
Запускайте её только после того, как просмотрели кадры глазами.
