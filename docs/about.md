# Что это и зачем

## Задача

Чтобы нейросеть научилась отличать, например, «пустую ленту» от «ленты с продуктом», ей нужно показать
много примеров каждого случая. Эти примеры берут из видео: из кадров вырезают нужный участок
и кладут в папку с названием случая (класса). Набор таких папок называют **датасетом**.

Собирать датасет вручную долго, и есть типичные проблемы:

- человек сохраняет много похожих кадров и пропускает редкие случаи;
- модель, которая уже работает, иногда уверенно ошибается, и кадр попадает не в ту папку;
- непонятно, какие кадры уже проверены, какие удалены, что уже отправлено на обучение.

## Что делает программа

- **Нарезает кадры** из видео — вручную по клавишам или автоматически по правилам.
- **Вырезает зоны** — нужные участки кадра (например, левую и правую ленту), по файлу разметки.
  Если зон нет, сохраняется весь кадр.
- **Раскладывает по папкам** — для классификации каждому классу своя папка; для детекции и сегментации —
  картинки и файлы разметки в формате YOLO.
- **Не даёт сохранить дубли** — если кадр почти такой же, как уже сохранённый, программа сообщит об этом
  и покажет похожий кадр.
- **Ищет подозрительные ответы модели** — например, среди многих «FULL» вдруг один «EMPTY». Такой кадр
  кладётся в отдельную папку `_suspect`, чтобы человек проверил его в первую очередь.
- **Ведёт историю** — какой кадр откуда взят, какой класс дала модель, что исправил человек.
- **Выгружает проверенное** — в виде папок, которые можно сразу загрузить в Roboflow.

## Как устроена работа

1. **Сбор.** Программа сохраняет кадры по папкам.
2. **Проверка глазами.** Вы открываете папки, переносите неверные кадры в правильные папки, удаляете мусор.
3. **Сверка.** Вы нажимаете «Сверить» (или запускаете `ndc sync`). Программа запоминает ваши исправления:
   перенесённые — с новым классом, удалённые — как отклонённые (и больше не будет собирать такие же).
4. **Выгрузка.** Проверенные кадры копируются в отдельную папку для обучения.

Проверку делает только человек. Программа никогда не считает кадры проверенными сама.
