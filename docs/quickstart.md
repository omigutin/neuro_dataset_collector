# Быстрый старт

## 1. Установка

Нужен Python 3.10 или новее.

```bash
pip install "neuro-dataset-collector[web,opencv]"
```

- `web` — веб-интерфейс;
- `opencv` — библиотека для работы с видео. Если в вашем проекте OpenCV уже установлен, `opencv` не указывайте.
  На сервере без экрана вместо `opencv` используйте `headless`.

Можно и без установки: скачать папку проекта и запускать `python run.py` (зависимости — `pip install numpy pydantic pyyaml opencv-python fastapi uvicorn`).

## 2. Запуск

```bash
python run.py      # из папки проекта
# или, если пакет установлен:
ndc web
```

Откроется браузер. При первом запуске создаётся файл настроек
`%APPDATA%\NeuroDatasetCollector\settings.yaml` (в Windows). При следующих запусках открываются те же настройки,
то же видео и тот же кадр, на котором вы остановились.

## 3. Настройки (один раз)

1. **Классы и клавиши** — кнопка ✎ под кадром: «+ Добавить класс», имя и клавиша (нажмите нужную клавишу,
   можно и `` ` `` слева от единицы). Буквы сами становятся заглавными.
2. ⚙ в верхней строке → **Где сохранять** — «рядом с каждым видео»: для видео `cam25_1315.avi` кадры лягут
   в папку `cam25_1315_dataset` рядом с ним.
3. ⚙ → **Файлы разметки** — папка боевой разметки: для видео «…cam25…» программа сама возьмёт «…cam25….json».
   Если рядом с видео есть своя разметка, берётся она.

Настройки сохраняются сразу, отдельной кнопки нет.

## 4. Нарезка

📁 в плейлисте — папка с видео: слева появится список всех видео папки и подпапок, щелчок открывает видео
(🎞 — одно видео). Под кадром отметьте, какие зоны резать (или щёлкните по зоне на кадре). Зоны правятся
в редакторе разметки — карандаш в правом верхнем углу кадра.

- `Пробел` — воспроизведение / пауза;
- `←` / `→` — шаг назад / вперёд (размер шага — «шаг» под кадром);
- `1`, `2`, `3`… — сохранить текущий кадр в класс (клавиши и число сохранённых — на кнопках под кадром);
- `s` (или своя клавиша) — сохранить без класса.

Справа — история: что сохранено и что нет и почему (у дубля — обе картинки). Ошибся с классом — «→ КЛАСС»
прямо в истории. Повторная нарезка того же видео ничего не затирает.

Автонарезка — «▶ Автонарезка» в верхней строке, для одного видео или всего плейлиста.

## 5. Проверка, сверка, выгрузка

📊 в верхней строке → «Весь плейлист»: сколько собрано по видео и классам. Откройте папки (📂), просмотрите
кадры, разложите ошибочные по правильным папкам, удалите лишние. Затем «Сверить» и «Выгрузить» — получится
одна папка с подпапками классов со всех видео, её можно целиком загрузить в Roboflow.

То же самое из командной строки:

```bash
ndc collect -c settings.yaml --source video.avi   # автонарезка по правилам
ndc sync -c settings.yaml --video video.avi       # сверка после проверки
ndc export -c settings.yaml --video video.avi -o D:/export
ndc stats -c settings.yaml --video video.avi
```

`--video` нужен, когда кадры лежат рядом с видео (галочка «рядом с видео»).
