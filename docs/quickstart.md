# Быстрый старт

## 1. Установка

Нужен Python 3.10 или новее.

```bash
pip install "neuro-frame-collector[web,opencv]"
```

- `web` — веб-интерфейс;
- `opencv` — библиотека для работы с видео. Если в вашем проекте OpenCV уже установлен, `opencv` не указывайте.
  На сервере без экрана вместо `opencv` используйте `headless`.

Проверка: команда `nfc --help` должна вывести список команд.

## 2. Файл настроек

```bash
nfc init nfc.yaml
```

Появится файл `nfc.yaml` с примером и пояснениями к каждой строке. Главное, что стоит поправить:

```yaml
task: classify                  # классификация
classes: [EMPTY, FULL, UNKNOWN] # ваши классы
catalog:
  root: D:/datasets             # куда складывать кадры
  collection: myproject/line1   # название набора
source:
  path: D:/videos/line1         # видео или папка с видео
  step: 5                       # смотреть каждый 5-й кадр
```

## 3. Нарезка в браузере

```bash
nfc web -c nfc.yaml
```

Откроется страница в браузере. Перейдите на вкладку **«Нарезка»**, нажмите **«Открыть видео из настроек»**.

- `Пробел` — воспроизведение / пауза;
- `←` / `→` — шаг назад / вперёд;
- `1`, `2`, `3`… — сохранить текущий кадр в класс (клавиши видны под кадром);
- `s` — сохранить без класса.

После каждого сохранения справа появляется сообщение: куда сохранён кадр или почему не сохранён
(например, «похож на уже сохранённый» — со ссылкой на похожий кадр).

## 4. Проверка и сверка

Откройте папку `D:/datasets/myproject/line1`. В ней папки классов. Просмотрите кадры,
перенесите ошибочные в правильные папки, удалите лишние. Затем на вкладке **«Итог»** нажмите **«Сверить»**.

## 5. Выгрузка

На вкладке **«Итог»** укажите папку выгрузки и нажмите **«Выгрузить»**. Получится папка с подпапками классов —
её можно целиком загрузить в Roboflow, он сам разложит картинки по классам.

То же самое без браузера:

```bash
nfc collect -c nfc.yaml        # автонарезка по правилам
nfc sync -c nfc.yaml           # сверка после проверки
nfc export -c nfc.yaml -o D:/export
nfc stats -c nfc.yaml          # сколько собрано
```
