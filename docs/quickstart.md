# Быстрый старт

## 1. Установка

Нужен Python 3.10 или новее.

```bash
pip install "neuro-dataset-collector[web,opencv]"
```

- `web` — веб-интерфейс;
- `opencv` — библиотека для работы с видео. Если в вашем проекте OpenCV уже установлен, `opencv` не указывайте.
  На сервере без экрана вместо `opencv` используйте `headless`.

Можно и без установки: скачать папку проекта и запускать `python run.py` (зависимости — `pip install numpy pydantic pyyaml opencv-python fastapi uvicorn`).

## 2. Запуск

```bash
python run.py      # из папки проекта
# или, если пакет установлен:
ndc web
```

Откроется браузер. При первом запуске создаётся файл настроек
`%APPDATA%\NeuroDatasetCollector\settings.yaml` (в Windows). При следующих запусках открываются те же настройки,
то же видео и тот же кадр, на котором вы остановились.

## 3. Настройки (один раз)

Вкладка **«Настройки»**:

1. **Классы** — кнопка «+ Добавить класс», имя и клавиша. Буквы сами становятся заглавными; русские буквы,
   пробелы и спецсимволы не вводятся.
2. **Куда сохранять** — галочка «рядом с видео»: для видео `cam25_1315.avi` кадры лягут в папку
   `cam25_1315_dataset` рядом с ним. У каждого видео своя папка — сразу видно, какие видео уже нарезаны.
3. **Зоны** — «Что вырезать: зоны из файла разметки», метки фигур (например, `CROP`) и, по желанию, папка
   с файлами разметки: тогда для видео «…cam25…» программа сама предложит «…cam25….json».
4. «Сохранить настройки».

## 4. Нарезка

Вкладка **«Нарезка»** → «Папка с видео…» (обычное окно выбора папки): слева появится список всех видео папки
и подпапок, щелчок открывает видео. Одно видео — «Одно видео…». Зоны можно поправить прямо на кадре
(«Править зоны»), исправленная разметка сохранится рядом с видео.

- `Пробел` — воспроизведение / пауза;
- `←` / `→` — шаг назад / вперёд;
- `1`, `2`, `3`… — сохранить текущий кадр в класс (клавиши видны под кадром);
- `s` — сохранить без класса.

Справа — что сохранено, а что нет и почему (например, «похож на уже сохранённый» — со ссылкой на похожий кадр).
Повторная нарезка того же видео ничего не затирает.

## 5. Проверка, сверка, выгрузка

Откройте папку `<имя видео>_dataset`, просмотрите кадры, разложите ошибочные по правильным папкам, удалите лишние.
Затем на вкладке **«Итог»** — «Сверить» и «Выгрузить». Получится папка с подпапками классов — её можно целиком
загрузить в Roboflow.

То же самое из командной строки:

```bash
ndc collect -c settings.yaml --source video.avi   # автонарезка по правилам
ndc sync -c settings.yaml --video video.avi       # сверка после проверки
ndc export -c settings.yaml --video video.avi -o D:/export
ndc stats -c settings.yaml --video video.avi
```

`--video` нужен, когда кадры лежат рядом с видео (галочка «рядом с видео»).
