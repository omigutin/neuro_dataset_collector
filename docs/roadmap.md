## Отбор по разнообразию (эмбеддинги)

Предобученная нейросеть (например, DINOv2 на PyTorch) превращает каждый вырез в набор чисел — «отпечаток смысла».
Похожие картинки получают близкие отпечатки. Из большого числа кандидатов выбирается K самых непохожих
друг на друга: первый — любой, каждый следующий — самый далёкий от уже выбранных. Редкие случаи попадают
в выборку первыми, однотипные — последними. Это лучший способ собрать стартовый набор без модели.

Планируется: повод `novelty` (сохранять, если кадр далёк от всех сохранённых) и команда отбора K лучших
из уже нарезанных кандидатов. Отдельная установка: `neuro-frame-collector[embeddings]`.

## Примеры классов (прототипы)

Положить несколько эталонных картинок каждого класса, а программа будет предлагать класс для новых кадров
по похожести. Риск: классы вроде `UNKNOWN` или разные виды `FULL` очень разнообразны, поэтому сначала
нужно проверить на реальных данных.

## Второе мнение

Сравнение ответа модели с другой моделью или с той же моделью на слегка изменённой картинке
(отражение, яркость). Расхождение — повод для проверки.
