# neuro_frame_collector — документация

**neuro_frame_collector** помогает собрать картинки из видео, чтобы обучить нейросеть.
Он вырезает нужные участки кадра, раскладывает их по папкам, не даёт сохранить одно и то же дважды
и помнит историю каждого кадра.
