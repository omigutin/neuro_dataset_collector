# Веб-интерфейс

Запуск из папки проекта:

```bash
python run.py                  # прошлый сеанс
python run.py мои_настройки.yaml
```

или, если пакет установлен, `ndc web` (`-c файл.yaml`, `--port 9000`, `--no-browser`).

Откроется браузер с адресом `http://127.0.0.1:8765/`. Остановить — `Ctrl+C` в окне, где запущена команда.
Веб-интерфейс работает на том компьютере, где запущен: кнопки «Выбрать…» открывают обычные окна выбора файла
или папки этого компьютера.

## Что запоминается

В `%APPDATA%\NeuroDatasetCollector\` (Windows) или `~/.config/neuro_dataset_collector/`:

- `settings.yaml` — настройки по умолчанию (если не указан свой файл);
- `session.yaml` — какой файл настроек, папка с видео, какое видео открыто и на каком кадре
  остановились в каждом видео.

При следующем запуске всё открывается как было.

## Вкладка «Нарезка»

| Строка | Что делать |
|---|---|
| Видео | «Папка с видео…» — все видео папки и подпапок попадут в плейлист слева; «Одно видео…» — открыть один файл |
| Зоны | «Файл разметки…» (LabelMe json) или «Весь кадр»; правка зон — кнопки на самом кадре |
| Датасет | куда сохраняются кадры этого видео |

**Плейлист** (слева): щелчок — открыть видео; «◀ пред.» / «след. ▶» или `PageUp` / `PageDown` — соседнее видео.
Число у видео — сколько кадров уже сохранено, под ним — по классам («EMPTY 12 · FULL 30 · _unsorted 3»);
📂 — открыть папку с кадрами этого видео в проводнике. Значок: 📌 — у видео есть свой файл разметки,
📷 — разметка найдётся по номеру камеры. Видео открывается на том кадре, где вы остановились в прошлый раз.

**Какой файл разметки берётся** при открытии видео:

1. json рядом с видео с тем же именем (`ml_cam30_0905.avi` → `ml_cam30_0905.json`);
2. иначе — файл с тем же номером камеры из папки разметки (настройки → «Зоны»);
3. иначе — тот, что был выбран раньше.

На кадре зелёным нарисованы зоны с номерами. Галочками под кадром выбирается, какие зоны сохранять.

### Правка зон

Кнопки в левом верхнем углу кадра:

| Кнопка | Что делает |
|---|---|
| ✏️ | войти в правку зон |
| 💾 | сохранить зоны и выйти из правки (`Enter`) |
| ↶ | отменить последнее действие (`Ctrl+Z`) |
| ✖ | выйти без сохранения (`Esc`) |
| ⤓ | сохранить разметку в файл (например, перезаписать файл камеры) |

В правке:

- тянуть за угол или сторону прямоугольника, за точку многоугольника; за середину зоны — перенос целиком;
- **добавить точку** — потянуть кружок «+» на стороне или дважды щёлкнуть по стороне. Прямоугольник после этого
  становится многоугольником;
- **удалить точку** — дважды щёлкнуть по ней или выбрать её и нажать `Delete` (меньше 3 точек не бывает);
- стрелки — сдвиг выбранной (жёлтой) зоны на 1 пиксель, с `Shift` — на 10; `Tab` — следующая зона.

После 💾 разметка сохраняется **рядом с видео** под его именем и дальше используется для этого видео.
Исходный файл не меняется. Чтобы перенести исправление в общий файл камеры, нажмите ⤓ — откроется папка
разметки с файлом этой камеры, его можно перезаписать.

Для многоугольников включите в настройках «закрасить всё вне многоугольника» — так кадры будут вырезаны
так же, как их вырезает Production Counter.

**Автонарезка по правилам** (справа вверху): «Это видео» — открытое видео, «Все видео плейлиста» — по очереди
все видео папки; у каждого видео свой файл разметки (по правилу выше) и своя папка датасета. Нарезка идёт
на полной скорости, а на месте кадра показывается тот, что обрабатывается сейчас: зона вспыхивает зелёным,
когда вырез сохранён, и красным, когда отказ. Сохранённые кадры сразу появляются в истории. Пока идёт
автонарезка, ручное сохранение отключено.

### История (справа)

История сгруппирована по видео: открытое видео (и то, что режется сейчас) — сверху и развёрнуто.

- щелчок по записи — открыть это видео на этом кадре;
- «→ FULL» и другие классы — перенести сохранённый кадр в папку другого класса (кадр считается
  проверенным человеком); только для классификации;
- 🗑 — удалить кадр в корзину Windows;
- отказ «похож на сохранённый» показывает обе картинки: что пытались сохранить и на что похоже
  (щелчок — крупно); «Сохранить всё равно» сохраняет этот вырез.

Сохранённые кадры берутся из истории каталога и видны после перезапуска, отказы — только за текущий
запуск программы.

## Вкладка «Настройки»

- **Классы** — таблица: «+ Добавить класс», «−» удаляет. Имя — латиница, цифры, `_`, `-`; буквы заглавные,
  пробел превращается в `_`, остальное не вводится. Клавиша — цифра или латинская буква, без повторов.
- **Куда сохранять** — «рядом с видео» (папка `<имя видео>_dataset`) или своя папка.
- **Зоны** — источник, папка с файлами разметки (подсказка по номеру камеры), метки фигур (таблица, как классы;
  регистр при сравнении с разметкой не важен).
- Редкие настройки — «Все настройки текстом (YAML)».

## Вкладка «Итог»

- **Сколько собрано** — по классам, состояниям и причинам отказов.
- **Сверить** — после ручной проверки папок.
- **Выгрузить** — копия проверенных кадров для обучения или загрузки в Roboflow.
