# Веб-интерфейс

Запуск из папки проекта:

```bash
python run.py                  # прошлый сеанс
python run.py мои_настройки.yaml
```

или, если пакет установлен, `ndc web` (`-c файл.yaml`, `--port 9000`, `--no-browser`).

Откроется браузер с адресом `http://127.0.0.1:8780/`. Остановить — `Ctrl+C` в окне, где запущена команда.
Если программа уже запущена, повторный запуск просто откроет её в браузере. Если порт занят другой
программой, берётся следующий свободный (адрес пишется в окне запуска).
Веб-интерфейс работает на том компьютере, где запущен: кнопки выбора открывают обычные окна выбора файла
или папки этого компьютера.

## Что запоминается

В `%APPDATA%\NeuroDatasetCollector\` (Windows) или `~/.config/neuro_dataset_collector/`:

- `settings.yaml` — настройки по умолчанию (если не указан свой файл);
- `session.yaml` — файл настроек, папка с видео, открытое видео, кадр, на котором остановились в каждом видео,
  какие зоны резать в каждом файле разметки и какая разметка выбрана вручную для видео.

## Страница

| Где | Что там |
|---|---|
| Верхняя строка | путь к открытому видео; **Разметка** — какой разметкой режется видео (щелчок — выбрать разметку, версию, открыть редактор, файл, резать весь кадр); **Модель** — какая модель выбрана (щелчок — показывать её ответы на кадре); **Задачи** — автонарезка и прогон моделью; **Настройки**; клавиши |
| Слева | режимы: **Нарезка**, **Журнал**, **Участки** (число неразобранных), **Проверка**, **Итог** |
| Внизу | подсказка по клавишам текущего режима и папка датасета |

Если с разметкой что-то не так (не найдена, явный файл от другой камеры, в файле нет нужных зон), «Разметка»
становится жёлтой, а над кадром — объяснение и кнопка «Открыть файл разметки…».

## Нарезка

Три колонки: видео — кадр — зоны и классы.

### Видео

«Папка…» — папка с видео (вместе с подпапками), «Файл…» — одно видео (списком станет его папка).
Видео сгруппированы по подпапкам, группу можно свернуть; поиск по имени, отбор «Все / Не начаты / С кадрами».
У видео: сколько кадров сохранено, полоска по классам, метки «журнал модели», «разметка рядом с видео», «боевая разметка»,
«отказов N»; значок папки — открыть папку его кадров. «Пред.» / «След.» или `PageUp` / `PageDown` — соседнее
видео. Видео открывается на том кадре, где вы остановились.

### Кадр

Над кадром — переключатели **Зоны** (рисовать зоны), **Ответы модели** (`Alt+M`: зона в цвете класса
с подписью «класс уверенность»), рядом — **Редактор разметки**.

Под кадром — плеер (шаг, скорость, «после сохранения — следующий шаг») и **шкала времени** на всё видео:

- **Модель** — ответы модели по выбранной зоне из журнала (цвет класса): видно, где модель меняет решение;
- **Сохранено** — отметки сохранённых кадров в цвете класса;
- **Участки** — участки на проверку, если открыт файл участков этого видео.

Щелчок по шкале — перейти к этому месту.

**Какая разметка берётся** при открытии видео (Настройки → «Файлы разметки» → «Какую разметку брать», по
умолчанию — авто):

1. рядом с видео — `ml_cam30_0905.markup.json`, текущая версия;
2. иначе — боевая из папки разметки, подобранная по имени и пути видео (иначе — файл с тем же номером камеры);
3. иначе — явный файл из настроек.

Старый `ml_cam30_0905.json` рядом с видео при первом открытии переносится в разметку рядом с видео версией v1.

В меню **Разметка** для открытого видео можно выбрать: авто, рядом с видео, боевую, явный файл («Открыть
файл разметки…»), версию разметки рядом с видео, а также резать весь кадр. Выбор запоминается за видео.

### Зоны и классы (справа)

- **Зоны на кадре** — галочка «резать» у каждой зоны (или щелчок по зоне на кадре) и ответ модели, если он
  включён. Выбор запоминается для камеры и действует и при ручном сохранении, и при автонарезке.
- **Сохранить кадр** — кнопки классов с клавишами и числом сохранённых в этом видео кадров; сохраняются
  отмеченные зоны. «Классы и клавиши…» — изменить классы.
- **Последние сохранения** — щелчок открывает кадр; «Вся история» — история по всем видео.
- **Папка датасета** этого видео.

| Клавиша | Действие |
|---|---|
| Пробел | воспроизведение / пауза |
| `→` / `←` | шаг вперёд / назад, с `Shift` — 10 шагов |
| `PageDown` / `PageUp` | следующее / предыдущее видео |
| клавиша класса | сохранить в класс |
| клавиша «без класса» | сохранить в «_unsorted» |
| `Shift` + клавиша класса | сохранить, даже если кадр похож на уже сохранённый |
| `Alt` + `M` | показать / скрыть ответы модели |

С включёнными ответами модели видно, где модель ошибается: нажмите клавишу правильного класса — кадр
сохранится, а ответ модели запишется вместе с ним (в истории — «модель: …»).

### Редактор разметки

«✏ Редактор разметки» над кадром (или в меню «Разметка») открывает редактор
[neuro_markup_lab](https://github.com/omigutin/neuro_markup_lab) поверх страницы — на той разметке, по которой
режется видео: рядом с видео (выбранная версия) или боевая. Там правятся контуры и атрибуты фигур, видны версии
разметки рядом с видео, их можно сравнить и сделать текущей.

- «Сохранить как новую версию» — разметка рядом с видео, новая версия становится текущей;
- «Сохранить в боевой JSON» — правка общего файла камеры (прежний файл остаётся рядом как `.bak`).

После сохранения сборщик сразу перечитывает зоны. Пока редактор открыт, клавиши классов кадры не сохраняют.
Отдельно редактор открывается по адресу `markup/` сборщика.

### История

«Вся история» — панель по видео: щелчок по записи — открыть видео на этом кадре; «→ КЛАСС» — перенести кадр
в папку другого класса (кадр считается проверенным человеком, полный кадр переносится вместе с ним);
«Удалить» — в корзину; отказ «похож на сохранённый» показывает обе картинки, «Сохранить всё равно» сохраняет
этот вырез. Сохранённые кадры видны и после перезапуска, отказы — только за текущий запуск.

## Задачи: автонарезка и прогон моделью

«Задачи» в верхней строке: что сделать (автонарезка или прогон моделью), какие видео (открытое или весь
плейлист), «Запустить». Пока задача идёт, рядом с кнопкой — ход, на месте кадра — обрабатываемый кадр,
в панели задач — «Остановить». Ручное сохранение на это время отключено.

**Автонарезка** — по правилам из Настройки → «Автонарезка». Без модели — кадр раз в заданное время без дублей,
класс не известен (кадры в «_unsorted»). С моделью — кадры, где модель не уверена (диапазон уверенности),
и небольшая доля «контрольных» кадров, где она уверена. Зона вспыхивает зелёным при сохранении и красным
при отказе.

**Проверка последовательности** (только с моделью): если среди устойчивого ряда одного класса мелькнул
другой (FULL FULL FULL EMPTY FULL FULL), это, скорее всего, ошибка модели — такой кадр уходит в «_suspect».

**Прогнать моделью** — модель отвечает по каждой зоне проверяемых кадров (шаг — «Проверять кадр моделью
раз в … с»), ответы пишутся в журнал (режим «Журнал», дорожка «Модель» на шкале). Если в Настройки →
«Прогон моделью» включено «сохранять вырезы, где модель не прошла условия», такие вырезы (низкая уверенность,
смена класса, отмеченные классы) сохраняются на проверку в «_suspect».

## Журнал

[Журнал](journal.md) — что модель ответила в каждой зоне каждого проверенного кадра. Пишут его «Прогнать
моделью» (журнал в папке «_journal» датасета видео) и регрессионный прогон Production Counter. Картинки не
хранятся: вырезы достаются из видео по номеру кадра и зоне — это «виртуальный датасет».

- слева — журнал (из папки видео с подпапками или «Открыть файл журнала…») и выборка: зона, ответ модели
  (со счётчиками, в том числе «нет ответа»), уверенность от–до, «Только смены класса» — кадры, где класс в зоне
  сменился по сравнению с прошлым кадром (там модель чаще ошибается);
- в центре — вырезы;
- справа — выбранный вырез на кадре целиком, ответ модели и вопрос «Какой здесь класс на самом деле?»:
  кнопка или клавиша класса сохраняет вырез и выделяет следующий, «Пропустить — модель права» (`→`) — дальше
  без сохранения, `Enter` — открыть кадр в нарезке. Ответ модели из журнала записывается вместе с кадром.

## Участки

Файл `….review.json`: где регрессионный прогон разошёлся с эталоном (пропуск, лишнее, изменено) или где человек
отметил ошибку. Открывается «Открыть…» или ссылкой из Production Counter (`?review=…`).

Слева — участки с ходом «Разобрано N из M» (отбор «Не разобраны / Все»). Выбранный участок: вид ошибки,
зона, время, что ожидалось и что получилось; кадр целиком с обведённой зоной; вырезы зоны на участке (до 48
кадров, кадр события обведён пунктиром) с ответами модели из журнала прогона; кнопки классов. «Отметить
разобранным» записывает отметку в файл и переходит к следующему участку.

## Проверка

Модель из настроек проверяет уже собранные кадры (классификация, «Открытое видео» или «Весь плейлист»):
кадры, где она не согласна с классом кадра или уверена меньше порога, и пары почти одинаковых кадров в разных
классах. У кадра: «→ класс модели» (модель права), «→ другой класс», «Верно» (убрать из списка), «Удалить».

## Итог

Сверху — «Открытое видео» или «Весь плейлист».

1. **Сколько собрано** — таблица «видео × класс», состояния и итог; «Папка» — папка кадров видео, щелчок по
   названию — открыть видео.
2. **Сверка после проверки** — просмотрите папки, перенесите ошибки в папки правильных классов, удалите мусор
   и нажмите «Сверить».
3. **Выгрузка** — одна папка со всех видео (подпапки классов) для Roboflow. «Выгрузить и полные кадры» —
   полные кадры в соседнюю папку «…_frames» с той же раскладкой.

## Настройки

Панель справа (кнопка «Настройки»); изменения сохраняются сразу. Сверху — файл настроек: «Открыть другой…»,
«Сохранить как…».

| Раздел | Что настраивается |
|---|---|
| Где сохранять | рядом с каждым видео (папка «имя видео_dataset») или в одну папку |
| Как сохранять кадр | полный кадр к каждому вырезу (папка `_frames`, те же классы), закраска вокруг многоугольной зоны, поля вокруг зоны, качество JPEG, что считать дублем, что делать с дублем при ручном сохранении |
| Файлы разметки | папка боевой разметки, какую разметку брать (авто, рядом с видео, боевая, явный файл) |
| Автонарезка | модель, «брать кадр не чаще раза в N с», пропуск почти одинаковых соседних кадров; с моделью — как часто проверять кадр моделью, диапазон уверенности, доля контрольных кадров, проверка последовательности (со схемой) |
| Прогон моделью | сохранять ли вырезы, где модель не прошла условия, и сами условия: уверенность ниже порога, смена класса, ответ — один из классов |
| Дополнительно | шаблон имени файла, подпапка внутри датасета, где искать дубли, все настройки текстом (YAML) |

## Внутри другого приложения

Сборщик можно открыть вкладкой в другом веб-приложении (например, NeuroFramework) — см.
[Подключение к своей программе](developers.md#веб-интерфейс-внутри-своего-приложения). Отдельный запуск
(`ndc web`, `python run.py`) работает как раньше.
