# Веб-интерфейс

Запуск из папки проекта:

```bash
python run.py                  # прошлый сеанс
python run.py мои_настройки.yaml
```

или, если пакет установлен, `ndc web` (`-c файл.yaml`, `--port 9000`, `--no-browser`).

Откроется браузер с адресом `http://127.0.0.1:8765/`. Остановить — `Ctrl+C` в окне, где запущена команда.
Веб-интерфейс работает на том компьютере, где запущен: кнопки «Выбрать…» открывают обычные окна выбора файла
или папки этого компьютера.

## Что запоминается

В `%APPDATA%\NeuroDatasetCollector\` (Windows) или `~/.config/neuro_dataset_collector/`:

- `settings.yaml` — настройки по умолчанию (если не указан свой файл);
- `session.yaml` — какой файл настроек, папка с видео, какое видео открыто и на каком кадре
  остановились в каждом видео.

При следующем запуске всё открывается как было.

## Вкладка «Нарезка»

| Строка | Что делать |
|---|---|
| Видео | «Папка с видео…» — все видео папки и подпапок попадут в плейлист слева; «Одно видео…» — открыть один файл |
| Зоны | «Править зоны», «Сохранить разметку в…», «Файл разметки…» (LabelMe json) или «Весь кадр» |
| Датасет | куда сохраняются кадры этого видео |

**Плейлист** (слева): щелчок — открыть видео; «◀ пред.» / «след. ▶» или `PageUp` / `PageDown` — соседнее видео.
Число у видео — сколько кадров уже сохранено. Значок: 📌 — у видео есть свой файл разметки, 📷 — разметка
найдётся по номеру камеры. Видео открывается на том кадре, где вы остановились в прошлый раз.

**Какой файл разметки берётся** при открытии видео:

1. json рядом с видео с тем же именем (`ml_cam30_0905.avi` → `ml_cam30_0905.json`);
2. иначе — файл с тем же номером камеры из папки разметки (настройки → «Зоны»);
3. иначе — тот, что был выбран раньше.

На кадре зелёным нарисованы зоны с номерами. Галочками под кадром выбирается, какие зоны сохранять.

### Правка зон

«Править зоны» → зоны можно двигать и менять прямо на кадре:

- тянуть за угол или сторону прямоугольника, за точку многоугольника;
- тянуть за середину зоны — перенос целиком;
- стрелки — сдвиг выбранной (жёлтой) зоны на 1 пиксель, с `Shift` — на 10; `Tab` — следующая зона;
- `Enter` или «Применить» — сохранить, `Esc` или «Отменить» — отказаться.

После «Применить» исправленная разметка сохраняется **рядом с видео** под его именем и дальше используется
для этого видео. Исходный файл разметки не меняется. Чтобы перенести исправление в общий файл камеры,
нажмите «Сохранить разметку в…» — откроется папка разметки с файлом этой камеры, его можно перезаписать.

| Клавиша | Действие |
|---|---|
| Пробел | воспроизведение / пауза |
| `→` / `←` | шаг вперёд / назад (на «шаг» кадров из настроек) |
| `Shift` + `→` / `←` | 10 шагов |
| `1`, `2`, … | сохранить в класс |
| `s` | сохранить без класса (для детекции — просто сохранить) |
| `Shift` + клавиша класса | сохранить, даже если кадр похож на уже сохранённый |

**Пошагово** (галочка под кадром): после сохранения сразу показывается следующий шаг.

**Автонарезка по правилам**: «Это видео» — открытое видео, «Все видео плейлиста» — по очереди все видео
папки; у каждого видео свой файл разметки (по правилу выше) и своя папка датасета.

## Вкладка «Настройки»

- **Классы** — таблица: «+ Добавить класс», «−» удаляет. Имя — латиница, цифры, `_`, `-`; буквы заглавные,
  пробел превращается в `_`, остальное не вводится. Клавиша — цифра или латинская буква, без повторов.
- **Куда сохранять** — «рядом с видео» (папка `<имя видео>_dataset`) или своя папка.
- **Зоны** — источник, папка с файлами разметки (подсказка по номеру камеры), метки фигур (таблица, как классы;
  регистр при сравнении с разметкой не важен).
- Редкие настройки — «Все настройки текстом (YAML)».

## Вкладка «Итог»

- **Сколько собрано** — по классам, состояниям и причинам отказов.
- **Сверить** — после ручной проверки папок.
- **Выгрузить** — копия проверенных кадров для обучения или загрузки в Roboflow.
