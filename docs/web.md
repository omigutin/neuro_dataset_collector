# Веб-интерфейс

Запуск из папки проекта:

```bash
python run.py                  # прошлый сеанс
python run.py мои_настройки.yaml
```

или, если пакет установлен, `ndc web` (`-c файл.yaml`, `--port 9000`, `--no-browser`).

Откроется браузер с адресом `http://127.0.0.1:8780/`. Остановить — `Ctrl+C` в окне, где запущена команда.
Если программа уже запущена, повторный запуск просто откроет её в браузере. Если порт занят другой
программой, берётся следующий свободный (адрес пишется в окне запуска).
Веб-интерфейс работает на том компьютере, где запущен: кнопки выбора открывают обычные окна выбора файла
или папки этого компьютера.

## Что запоминается

В `%APPDATA%\NeuroDatasetCollector\` (Windows) или `~/.config/neuro_dataset_collector/`:

- `settings.yaml` — настройки по умолчанию (если не указан свой файл);
- `session.yaml` — файл настроек, папка с видео, открытое видео, кадр, на котором остановились в каждом видео,
  и какие зоны резать в каждой камере.

## Страница

Всё на одной странице:

| Где | Что там |
|---|---|
| Верхняя строка | файл настроек (📂 открыть другой, 💾 сохранить в файл), автонарезка, ⚙ настройки, 📊 итог, ? клавиши |
| Слева | плейлист |
| В центре | кадр, плеер, зоны, кнопки классов |
| Справа | история |

### Плейлист

📁 — папка с видео (вместе с подпапками), 🎞 — одно видео (плейлистом станет его папка).
Видео сгруппированы по подпапкам, группу можно свернуть; поле «Фильтр» ищет по имени.
Под видео — сколько кадров сохранено по классам, 📂 — открыть папку с его кадрами.
📌 — у видео свой файл разметки, 📷 — разметка найдётся по номеру камеры.
◀ ▶ или `PageUp` / `PageDown` — соседнее видео. Видео открывается на том кадре, где вы остановились.

### Кадр

Над кадром — название видео, «Зоны: … ▾» (выбрать файл разметки, резать весь кадр, сохранить разметку
в файл) и «📂 Датасет» — папка кадров этого видео.

**Какой файл разметки берётся** при открытии видео:

1. json рядом с видео с тем же именем (`ml_cam30_0905.avi` → `ml_cam30_0905.json`);
2. иначе — файл с тем же номером камеры из папки разметки (⚙ → «Файлы разметки»);
3. иначе — тот, что был выбран раньше.

**Какие зоны резать** — галочки «Резать зоны» под кадром или щелчок по зоне на кадре. Выключенные зоны
нарисованы серым. Выбор запоминается для камеры (файла разметки) и действует и при ручном сохранении,
и при автонарезке.

**Плеер**: ⏮ ▶ ⏭, ползунок, номер кадра, скорость и **шаг** — на сколько кадров переходить стрелками и при
воспроизведении. «Пошагово» — после сохранения сразу показать следующий шаг.

**Кнопки классов** — с клавишей и числом уже сохранённых в этом видео кадров. ✎ — классы и клавиши
(клавиша — цифра, латинская буква или `` ` - = [ ] ; ' , . / ``; раскладка не важна).

| Клавиша | Действие |
|---|---|
| Пробел | воспроизведение / пауза |
| `→` / `←` | шаг вперёд / назад, с `Shift` — 10 шагов |
| `PageDown` / `PageUp` | следующее / предыдущее видео |
| клавиша класса | сохранить в класс |
| клавиша «без класса» | сохранить в «_unsorted» |
| `Shift` + клавиша класса | сохранить, даже если кадр похож на уже сохранённый |

### Правка зон

Кнопки в левом верхнем углу кадра:

| Кнопка | Что делает |
|---|---|
| ✏️ | войти в правку зон |
| 💾 | сохранить зоны и выйти из правки (`Enter`) |
| ↶ | отменить последнее действие (`Ctrl+Z`) |
| ✖ | выйти без сохранения (`Esc`) |
| ⤓ | сохранить разметку в файл (например, перезаписать файл камеры) |

В правке: тянуть за угол или сторону прямоугольника, за точку многоугольника; за середину зоны — перенос;
кружок «+» на стороне или двойной щелчок по стороне — новая точка (прямоугольник становится многоугольником);
двойной щелчок по точке или `Delete` — удалить точку; стрелки — сдвиг зоны (с `Shift` — на 10); `Tab` —
следующая зона.

После 💾 разметка сохраняется **рядом с видео** под его именем и дальше используется для этого видео.
Исходный файл не меняется. Чтобы перенести исправление в общий файл камеры, нажмите ⤓.

### История

Справа, по видео: открытое видео и то, что режется сейчас, — сверху.

- щелчок по записи — открыть это видео на этом кадре;
- «→ FULL» и другие классы — перенести кадр в папку другого класса (кадр считается проверенным человеком);
  полный кадр, если сохранялся, переносится вместе с ним;
- 🗑 — удалить кадр в корзину;
- отказ «похож на сохранённый» показывает обе картинки; «Сохранить всё равно» сохраняет этот вырез.

Сохранённые кадры видны и после перезапуска, отказы — только за текущий запуск.

## Автонарезка

В верхней строке: «▶ Автонарезка», рядом — «это видео» или «весь плейлист», ■ — остановить. Полоска
показывает ход. На месте кадра виден обрабатываемый кадр: зона вспыхивает зелёным при сохранении и красным
при отказе; сохранённые кадры сразу появляются в истории. Пока идёт автонарезка, ручное сохранение отключено.
Правила — в ⚙ → «Автонарезка».

## ⚙ Настройки

Панель справа; изменения сохраняются сразу.

| Раздел | Что настраивается |
|---|---|
| Где сохранять | рядом с каждым видео (папка «имя видео_dataset») или в одну папку |
| Как сохранять кадр | полный кадр к каждому вырезу (папка `_frames`, те же классы), закраска вокруг многоугольной зоны, поля вокруг зоны, качество JPEG, что считать дублем, что делать с дублем при ручном сохранении |
| Файлы разметки | папка с json камер |
| Автонарезка | модель, «брать кадр не чаще раза в N с», пропуск почти одинаковых соседних кадров; с моделью — как часто проверять кадр моделью, диапазон уверенности, доля контрольных кадров, проверка последовательности (со схемой) |
| Дополнительно | шаблон имени файла, подпапка внутри датасета, где искать дубли, все настройки текстом (YAML) |

**Без модели** автонарезка берёт кадр раз в заданное время и не сохраняет дубли; класс не известен —
кадры попадают в «_unsorted». **С моделью** сохраняются кадры, где модель не уверена (диапазон уверенности),
и небольшая доля «контрольных» кадров, где она уверена, — чтобы проверить, не ошибается ли она уверенно.

**Проверка последовательности** (только с моделью): если среди устойчивого ряда одного класса мелькнул
другой (FULL FULL FULL EMPTY FULL FULL), это, скорее всего, ошибка модели — такой кадр уходит в «_suspect».
Схема в настройках показывает, какие кадры будут отмечены при выбранных значениях.

## 📊 Итог, сверка и выгрузка

Сверху — «Это видео» или «Весь плейлист».

1. **Сколько собрано** — таблица «видео × класс», состояния и итог; 📂 — папка кадров видео, щелчок по
   названию — открыть видео.
2. **Проверка** — просмотрите папки, перенесите ошибки в папки правильных классов, удалите мусор и
   нажмите «Сверить».
3. **Выгрузка** — одна папка со всех видео (подпапки классов) для Roboflow. «Выгрузить и полные кадры» —
   полные кадры в соседнюю папку «…_frames» с той же раскладкой.
