# Веб-интерфейс

Запуск:

```bash
nfc web -c nfc.yaml
```

Откроется браузер с адресом `http://127.0.0.1:8765/`. Остановить — `Ctrl+C` в окне, где запущена команда.
Параметры: `--port 9000` — другой порт, `--no-browser` — не открывать браузер.

Если файла настроек ещё нет, запустите `nfc web` без `-c`, заполните настройки и нажмите «Сохранить как».

Веб-интерфейс работает на том компьютере, где запущен. Кнопки «…» открывают окно выбора файлов и папок
именно этого компьютера.

## Вкладка «Настройки»

Основные настройки собраны в карточки. Внизу — «Сохранить настройки». Если что-то заполнено неверно,
под формой появится список ошибок.

Редкие настройки можно поменять в разделе «Все настройки текстом (YAML)» и нажать «Применить YAML».

## Вкладка «Нарезка»

1. «Открыть видео из настроек» или «Выбрать видео…».
2. Если видео несколько — выберите нужное в списке.
3. На кадре зелёным нарисованы зоны с номерами. Галочками под кадром выбирается, какие зоны сохранять.

Клавиши:

| Клавиша | Действие |
|---|---|
| Пробел | воспроизведение / пауза |
| `→` / `←` | шаг вперёд / назад (на `step` кадров) |
| `Shift` + `→` / `←` | 10 шагов |
| `1`, `2`, … | сохранить в класс (назначаются в настройках) |
| `s` | сохранить без класса (для детекции — просто сохранить) |
| `Shift` + клавиша класса | сохранить, даже если кадр похож на уже сохранённый |

**Пошаговый режим** (галочка сверху): видео стоит на месте; после сохранения кадра автоматически
показывается следующий шаг. Удобно для быстрой разметки: смотришь — жмёшь цифру — следующий кадр.

Справа — **последние действия**: что сохранено (со ссылкой на файл) и что отклонено (с причиной и ссылкой
на похожий кадр).

**Автонарезка по правилам** прогоняет все открытые видео через автоотбор из настроек. Если в настройках
указана модель, кадры сразу раскладываются по классам, которые дала модель.

## Вкладка «Итог»

- **Сколько собрано** — по классам, состояниям и причинам отказов.
- **Сверить** — после ручной проверки папок.
- **Выгрузить** — копия проверенных кадров для обучения или загрузки в Roboflow.
