# Все настройки

Настройки хранятся в YAML-файле. Пример с пояснениями создаёт команда `nfc init`.
Пути можно писать относительно папки, где лежит файл настроек. Опечатка в названии настройки — ошибка
(программа не будет молча игнорировать неизвестное).

## Верхний уровень

| Настройка | По умолчанию | Что значит |
|---|---|---|
| `task` | `classify` | `classify`, `detect` или `segment` |
| `classes` | `[]` | список классов; для детекции порядок = номера классов в YOLO |
| `unsorted_label` | `_unsorted` | папка для кадров без класса |
| `predictions_space` | `region` | в каких координатах программа передаёт ответы модели: `region` — внутри выреза, `frame` — во всём кадре |

## `catalog` — где хранить

| Настройка | По умолчанию | Что значит |
|---|---|---|
| `root` | `datasets` | корневая папка; в ней `catalog.sqlite` с историей |
| `collection` | `default` | имя набора; уровни через `/` становятся вложенными папками |
| `dedup_scope` | `collection` | где искать похожие кадры: `collection` — в этом наборе, `catalog` — во всех |

## `regions` — зоны

| Настройка | По умолчанию | Что значит |
|---|---|---|
| `source` | `none` | `none` — весь кадр; `file` — из файла LabelMe; `api` — передаёт программа |
| `file` | — | файл LabelMe (`.json`) |
| `labels` | `[]` | брать фигуры только с этими метками; пусто — все |
| `where` | `{}` | доп. отбор по полям фигуры, например `{position: left}` |
| `id_field` | — | поле фигуры, которое станет номером зоны (например, `wz`); иначе «метка + порядковый номер» |
| `mask_outside` | `false` | закрасить чёрным всё вне многоугольника |
| `padding` | `0` | отступ вокруг зоны, пикселей |
| `fallback_to_full_frame` | `true` | если файл не найден — сохранять весь кадр (иначе ошибка) |

Из LabelMe берутся фигуры `polygon` и `rectangle`; линии и точки пропускаются. Если размер видео отличается
от размера картинки в файле разметки, зоны масштабируются.

## `manual` — ручное сохранение

| Настройка | По умолчанию | Что значит |
|---|---|---|
| `keys` | `{}` | клавиша → класс, например `{"1": EMPTY, "2": FULL}` |
| `save_all_key` | `s` | клавиша «сохранить без класса» |
| `on_duplicate` | `reject` | похожий кадр: `reject` — не сохранять и показать похожий, `warn` — сохранить с предупреждением, `allow` — сохранять молча |

## `auto` — автоотбор

| Настройка | По умолчанию | Что значит |
|---|---|---|
| `enabled` | `true` | включён ли автоотбор |
| `triggers` | `[confidence max 0.8]` | поводы; достаточно одного |
| `limits` | `[interval 1 с, dedup]` | ограничения; нужно пройти все, проверяются по порядку |

| `per_label` | `{}` | особые правила для отдельных классов (см. ниже) |

Поводы:

| Тип | Параметры | Что значит |
|---|---|---|
| `always` | — | каждый кадр |
| `confidence` | `min` (0), `max` (1), `include_empty` (true) | уверенность модели в диапазоне; `include_empty` — срабатывать, если модель ничего не нашла |
| `audit` | `rate` (0.02), `seed` | доля случайных кадров |

Ограничения:

| Тип | Параметры | Что значит |
|---|---|---|
| `interval` | `seconds` или `frames`, `per` (`[source, region, label]`) | не чаще одного раза за интервал; `per` — для чего считать отдельно |
| `scene_change` | `min_diff` (6) | средняя разница яркости с прошлым сохранением, от 0 до 255 |
| `quota` | `per_label`, `total` | максимум кадров на класс и всего (с учётом уже собранных) |
| `dedup` | `threshold` (5) | порог похожести от 0 до 64: чем меньше, тем строже совпадение |

Особые правила по классам (`per_label`) — только для классификации:

```yaml
auto:
  per_label:
    EMPTY: {enabled: false}                    # EMPTY автоматически не сохранять
    FULL: {max_conf: 0.9, interval_seconds: 5} # FULL — при уверенности до 0.9 и не чаще раза в 5 с
    _unsorted: {enabled: false}                # кадры, где модель ничего не нашла
```

| Параметр | Что значит |
|---|---|
| `enabled` | `false` — класс не сохраняется автоматически (вручную — можно) |
| `min_conf`, `max_conf` | свой диапазон уверенности для повода `confidence` |
| `interval_seconds` | свой интервал для ограничения `interval` (если интервал задан в секундах) |

В веб-интерфейсе эти правила меняются в разделе «Все настройки текстом (YAML)».

Совет: дешёвые ограничения (`interval`, `scene_change`) ставьте перед `dedup`.

## `consistency` — проверка последовательности (только `classify`)

| Настройка | По умолчанию | Что значит |
|---|---|---|
| `enabled` | `false` | включить |
| `context` | `5` | сколько одинаковых ответов нужно до и после выброса |
| `max_run` | `2` | выброс — не длиннее стольких кадров подряд |
| `review_always` | `[]` | классы, которые никогда не исправляются автоматически |
| `trusted_flips` | `{}` | автоисправление: `{EMPTY: [FULL]}` — EMPTY среди FULL сразу станет FULL |

## `storage` — файлы

| Настройка | По умолчанию | Что значит |
|---|---|---|
| `filename` | `{source}_r{region}_f{frame:06d}` | шаблон имени без расширения |
| `image_format` | `jpg` | `jpg` или `png` |
| `jpeg_quality` | `95` | качество JPEG, от 10 до 100 |
| `keep_source_frame` | `false` | дополнительно сохранять полный кадр в `_frames/` |
| `min_free_gb` | `1.0` | не сохранять, если на диске меньше этого места |

Поля шаблона имени: `{source}` — имя видео, `{region}` — номер зоны (`full` для всего кадра),
`{frame}` — номер кадра (`{frame:06d}` — шестью цифрами), `{label}`, `{conf}`, `{mode}` (`auto`/`manual`),
`{date}`, `{time}`, `{collection}`. Если имя совпадает с уже существующим, добавляется `_2`, `_3`…

## `runtime` — режим работы

| Настройка | По умолчанию | Что значит |
|---|---|---|
| `profile` | `dev` | `production` включает фоновую запись, отключение при ошибке и лимит 300 в час |
| `async_write` | `true` | писать файлы в фоне |
| `queue_size` | `64` | размер очереди записи; при переполнении кадр пропускается |
| `max_saves_per_hour` | — | лимит автосохранений в час |
| `disable_on_error` | `false` | при ошибке выключать сборщик вместо остановки программы |

## `source` — видео

| Настройка | По умолчанию | Что значит |
|---|---|---|
| `path` | — | файл или папка с видео |
| `extensions` | `[.mp4, .avi, .mov, .mkv]` | какие файлы считать видео |
| `recursive` | `false` | искать во вложенных папках |
| `step` | `1` | брать каждый N-й кадр |

## `model` — модель для офлайн-нарезки

| Настройка | По умолчанию | Что значит |
|---|---|---|
| `path` | — | файл модели ultralytics (`.pt`); нужен пакет `ultralytics` |
| `device` | — | `cpu`, `cuda:0`… |
| `conf` | `0.05` | минимальная уверенность для детекции |
