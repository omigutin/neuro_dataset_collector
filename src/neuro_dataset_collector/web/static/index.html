Для видео «…cam25…» берётся «…cam25….json» из этой папки, если рядом с видео нет своего json. Какие зоны резать, выбирается под кадром и запоминается для каждой камеры.

Автонарезка

Модель отвечает по каждому кадру. Если среди устойчивого ряда одного класса мелькнул другой класс — скорее всего, ошибка модели: такой кадр уходит в «_suspect» на проверку глазами.
