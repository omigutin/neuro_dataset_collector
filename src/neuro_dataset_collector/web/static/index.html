      Файлы разметки
      
      
      
Боевая разметка подбирается по имени и пути видео (для «…cam25…» — файл с «cam25» в имени).
        Разметка рядом с видео — «<имя>.markup.json» с версиями; правится в редакторе разметки.
        Для одного видео разметку можно выбрать в меню «Разметка» вверху. Какие зоны резать, выбирается под кадром
        и запоминается за файлом разметки.

    


    

      Автонарезка
      
      

      
      
      

        
        
        
        

          
          
Модель отвечает по каждому кадру. Если среди устойчивого ряда одного класса мелькнул другой класс —
            скорее всего, ошибка модели: такой кадр уходит в «_suspect» на проверку глазами.

          

          
          
          
          
Только на ручную проверку (не исправлять автоматически):

          

        

      

    


    

      Прогон моделью
      
«Прогнать моделью» в верхней строке: модель отвечает по каждой зоне проверяемых кадров
        (шаг — «Проверять кадр моделью раз в … с»), ответы пишутся в журнал (папка «_journal» в датасете видео).
        Журнал открывается во вкладке «Журнал» справа.

Поля: {source} — видео, {region} — зона, {frame:06d} — номер кадра, {label} — класс,
        {conf} — уверенность модели, {mode} — вручную/авто, {date}, {time}
