Файлы разметки

Для видео «…cam25…» берётся «…cam25….json» из этой папки, если рядом с видео нет своего json. Какие зоны резать, выбирается под кадром и запоминается для каждой камеры.

Автонарезка

Модель отвечает по каждому кадру. Если среди устойчивого ряда одного класса мелькнул другой класс — скорее всего, ошибка модели: такой кадр уходит в «_suspect» на проверку глазами.

Только на ручную проверку (не исправлять автоматически):
Прогон моделью

«Прогнать моделью» в верхней строке: модель отвечает по каждой зоне проверяемых кадров (шаг — «Проверять кадр моделью раз в … с»), ответы пишутся в журнал (папка «_journal» в датасете видео). Журнал открывается во вкладке «Журнал» справа.

Модель из настроек проверяет уже собранные кадры: где она не согласна с классом кадра (или не уверена)
      и какие почти одинаковые кадры лежат в разных классах. Кадры «без класса» не проверяются.
