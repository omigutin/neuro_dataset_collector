    Последние действия

      Файл настроек

      Настройки и открытое видео запоминаются: при следующем запуске всё откроется как было.

      Задача и классы

      КлассКлавиша

      Латиница, цифры, «_» и «-»; буквы становятся заглавными. Клавиша — цифра или латинская буква.

      Куда сохранять

      Поля: {source} {region} {frame:06d} {label} {conf} {mode} {date} {time}

      Повторная нарезка того же видео ничего не затирает: имена уникальны, похожие кадры отклоняются.

      Зоны

      Файл разметки выбирается на вкладке «Нарезка» для каждого видео.

      Для видео «…cam25…» будет предложен файл «…cam25….json» из этой папки.

      Метки фигур (пусто — все)

      Видео и модель

      Автоотбор: поводы сохранить (любой)

      Ограничения (все)

      Проверка последовательности

      Только для классификации с моделью. Короткий «выброс» другого класса среди устойчивого уходит в папку «_suspect» для ручной проверки.

      Отмеченные классы только для ручного решения (никогда не исправляются автоматически).

      Режим

      Все настройки текстом (YAML)

      Сколько собрано

      Сверка после проверки

      1. Откройте папку датасета и просмотрите кадры глазами.
      2. Неверные перенесите в папку правильного класса, мусор удалите.
      3. Нажмите «Сверить» — всё, что лежит в папках классов, будет считаться проверенным.
